## Featured Projects

**[Perishable Demand Forecasting](https://github.com/AniketKulkarni19/perishable-demand-forecasting)** — [Live demo](https://perishable-demand-forecasting-yqyz9zztek2qmerncudrxf.streamlit.app/)
